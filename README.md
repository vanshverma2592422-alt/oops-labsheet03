# OOPS Lab Sheet 03 - Java Array Programs

This folder contains 30 separate Java programs about one-dimensional, two-dimensional, three-dimensional, and jagged arrays. Each program has its own class, creates an object in `main`, and calls an instance method to perform the main task. Programs read their values from the terminal with `Scanner`.

## Compile and Run

Open PowerShell in this folder and compile all programs into `out`:

```powershell
javac -d out *.java
```

Run a program using its class name. For example:

```powershell
java -cp out labsheet03.Question01DisplayFiveIntegers
java -cp out labsheet03.Question30SparseMatrix
```

The programs for fixed-size arrays use the dimensions stated in their questions. Other programs ask for the array or matrix dimensions before reading values.
